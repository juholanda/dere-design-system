# DeRE — Design System

Vitrine (catálogo navegável) e tokens do design system da plataforma DeRE.
Abra `index.html` para ver todos os componentes e estados.

- `ds.css` — tokens (variáveis CSS, light/dark) + componentes por classe.
- `ds-tailwind.js` — mapeia os tokens para utilitários do Tailwind (CDN).
- `themes/` — variações de tema.

Identidade baseada no gov.br / Receita Federal (azul #1351b4, navy #071d41, fundo branco, raio 4px).
